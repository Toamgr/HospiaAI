# HESTIA Domain Intelligence

This folder organizes domain-specific product thinking and intelligence by operational area.

Each subfolder is a home for consolidated knowledge about one domain of hospitality operations — not code documentation, but the product and hospitality thinking that should inform future development in that domain.

---

## How to Use This Folder

When a domain area accumulates enough distinct product thinking that it warrants its own documentation — beyond what fits in the architecture files or master memory — create or expand its subfolder here.

This is not where code documentation goes. It is where the *product intelligence* for a domain lives: what hospitality problems the domain solves, what the right product decisions look like, and what HESTIA should know about this domain before building in it.

For active research and unvalidated theories, use `docs/research/` instead.
