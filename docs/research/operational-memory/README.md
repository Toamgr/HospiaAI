# Research: Operational Memory

Research into how venues remember, learn, and compound operational knowledge.

The Memory and Learning loops (from the Six Operational Loops) are where HESTIA's moat lives — and they are the least complete systems currently in the product.

Place here: models for memory architecture, provenance and confidence systems, memory recall pattern research, and investigations into what operational memory hospitality teams actually need and use.

The live memory model today is flat (type/title/detail/date). The structured model in `hospitalityMemoryMap.js` is the target. This folder holds the research that informs the path between them.
